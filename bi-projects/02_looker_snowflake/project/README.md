# LookML project files

This folder holds the LookML code for the [KPI Dashboard with Looker and Snowflake](../README.md) project.

| Folder | What it holds |
|---|---|
| `models/` | LookML model: connection and explores to include |
| `views/` | One view per Snowflake table: dimensions and measures |
| `explores/` | Joins between the views |
| `dashboards/` | LookML dashboard for the KPIs |
| `source_files/` | CSV files to load into Snowflake `RAW` |

Follow the steps in the [project README](../README.md).
